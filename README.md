# 555 Timer LED Blinker PCB

A 555 Timer based LED Blinker PCB designed using KiCad.

## Project Overview

This project is a simple LED blinker circuit using the NE555 timer IC in astable mode. The PCB was designed from schematic creation to routing, DRC verification and Gerber generation.

## Components

- NE555D Timer IC
- R1 = 1kΩ
- R2 = 10kΩ
- R3 = 330Ω
- C1 = 10µF
- C2 = 100nF
- D1 = LED
- J1 = 2-Pin Screw Terminal

## Design Workflow

1. Schematic Design
2. Footprint Assignment
3. Component Placement
4. PCB Layout
5. Track Routing
6. GND Copper Zone
7. Design Rule Check
8. 3D PCB Visualization
9. Gerber and Drill File Generation
10. Gerber Verification

## DRC Result

- Unconnected Items: 0
- Errors: 0
- Warnings: 0
